# Bảng thuật ngữ giao diện AHSO CRM (EN → VI)

Chuẩn duy nhất cho mọi chữ hiển thị cho người dùng. Khi dịch/viết UI mới, dùng đúng cột "Dùng".
`tools/ahso-ui-qa/scripts/static_checks.py` cảnh báo (WARN loanword) khi câu tiếng Việt còn lẫn từ ở cột trái.
